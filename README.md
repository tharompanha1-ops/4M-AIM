# 📚 MY BOOKSHELF — Online Free E-Book Library & AI Assistant

**MY BOOKSHELF** គឺជាគេហទំព័របណ្ណាល័យឌីជីថល សម្រាប់ចែករំលែកសៀវភៅ និងប្រភពស្វ័យសិក្សាដោយឥតគិតថ្លៃ ព្រមទាំងមានបំពាក់ប្រព័ន្ធ **AI Assistant** សម្រាប់ជួយឆ្លើយសំណួរ និងដោះស្រាយលំហាត់ជូនអ្នកសិក្សាភ្លាមៗ។

---

## 🌟 មុខងារសំខាន់ៗ (Features)

* 📖 **បណ្ណាល័យសៀវភៅឥតគិតថ្លៃ (Free E-Books):** ស្វែងរក និងទាញយកសៀវភៅសិក្សាបានដោយសេរី។
* 🤖 **AI Chatbot ជំនួយការសិក្សា:** ជួយឆ្លើយសំណួរ សម្រាយមេរៀន និងដោះស្រាយលំហាត់ម្ដងមួយជំហានៗ។
* 📩 **ទម្រង់ទំនាក់ទំនងឆ្លាតវៃ (Contact Form):** ផ្ញើសារសាកសួរ ឬរាយការណ៍ បញ្ជូនចូល **Telegram Bot** និង **Email** របស់ Admin ដោយផ្ទាល់ (Real-time Notification)។
* 📱 **Responsive Design:** បង្ហាញរូបរាងស្អាត និងដើរយ៉ាងរលូនលើគ្រប់ឧបករណ៍ (Mobile, Tablet, Desktop)។
* ⚖️ **Terms & Privacy Policies:** មានទំព័រព័ត៌មានច្បាប់ និងលក្ខខណ្ឌប្រើប្រាស់ផ្លូវការ។
